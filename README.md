# casamiento-

Invitación de boda animada en formato historias (estilo Instagram) — 7 de noviembre de 2026.

## Cómo personalizarla

Abrí `index.html` y editá el bloque `CONFIG` al principio del `<script>`:
nombres, horarios, lugares, links de Google Maps, dress code, fecha límite para confirmar y número de WhatsApp.

## Cómo usarla

- Tocá a la derecha para avanzar y a la izquierda para volver. Mantené apretado para pausar.
- Para publicarla gratis: en GitHub, **Settings → Pages → Deploy from branch** y elegí la rama. Después compartí el link por WhatsApp.
