## Historias

1. Sobre con sello de cera que se abre
2. ¡Nos casamos!
3. Cordón de tres dobleces (Eclesiastés 4:12)
4. Guarda la fecha
5. Cuenta regresiva
6. Dónde y cuándo (link a Google Maps)
7. Dress code semi formal + piscina
8. Regalos: luna de miel en familia (datos bancarios con botón para copiar)
9. Confirmar asistencia por WhatsApp

## Cómo usarla

- Toca a la derecha para avanzar y a la izquierda para volver. Mantén presionado para pausar.
- Para publicarla gratis: en GitHub, **Settings → Pages → Deploy from branch** y elige la rama. Después comparte el link por WhatsApp.
